# Безопасность

MurchCalc — клиентское приложение, работающее полностью в браузере.
Сервера и бэкенда нет; все данные остаются на устройстве пользователя.

## Модель угроз

| Угроза | Меры защиты |
|--------|-------------|
| XSS при выводе результатов | Пользовательские данные выводятся через `textContent`, не `innerHTML`. |
| Инъекция кода через выражения | Собственный парсер; `eval()` и `new Function()` запрещены. |
| Некорректный ввод | Строгая токенизация; ошибки перехватываются и не роняют приложение. |
| Зависимости | Регулярный `npm audit`; минимум пакетов (только decimal.js). |

## Приватность

- Данные не отправляются на внешние серверы.
- Хранение — только локально (LocalStorage/IndexedDB).

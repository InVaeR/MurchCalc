# MurchCalc

Браузерный калькулятор с расширяемой архитектурой, включающий различные режимы (basic, text, spreadsheet) и поддерживающий сложные математические вычисления.

## Особенности

- **Text Mode** (основная фича): Построчный ввод выражений с поддержкой переменных, комментариев и мгновенного пересчёта
- **Spreadsheet Mode**: Excel-подобный интерфейс с ячейками и формулами
- **Basic Mode**: Классический калькулятор с кнопками
- **Персистентное хранение** через LocalStorage/IndexedDB
- **Модульная архитектура** для добавления новых режимов
- **Точная арифметика** с использованием decimal.js

## Быстрый старт

```bash
npm install
npm run dev
```

## Система билда

- **Основной стек**: TypeScript + Vite (UI-фреймворк пока не подключён)
- **Парсер**: Реализован собственный парсер выражений
- **Вычисления**: decimal.js для точных чисел
- **Тесты**: Vitest для unit-тестов
- **Деплой**: GitHub Pages через GitHub Actions

## Структура проекта

> Реализовано: ядро (`src/core/`), режимы **Text** и **Basic** (`src/modes/`),
> UI-оболочка с темами (`src/ui/`) и автосохранение (`src/storage/`).
> В планах: Spreadsheet Mode, экспорт/импорт, IndexedDB.

```
src/
├── core/                  # Математический движок (независимый от UI)
│   ├── engine/            # Lexer, Parser, Evaluator
│   └── context/           # Переменные, состояние вычислений
├── modes/                 # Плагины режимов
│   ├── text/             # Text Mode (заметки)
│   ├── spreadsheet/      # Spreadsheet Mode
│   └── basic/            # Basic Mode
├── ui/                    # Компоненты интерфейса
│   ├── components/        # React-совместимые компоненты
│   ├── layout/            # Страницы и макеты
│   └── theme/             # Стиль для тёмной/светлой темы
├── storage/               # Хранение данных
└── utils/                 # Вспомогательные функции
```

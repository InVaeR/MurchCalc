# MurchCalc

Браузерный калькулятор с расширяемой архитектурой: несколько режимов на одном
математическом ядре с точной десятичной арифметикой.

## Режимы

- **Text Mode** (основная фича): построчный ввод выражений с переменными
  (`x = 10`), ссылкой на предыдущий результат (`prev`), комментариями (`//`)
  и мгновенным пересчётом.
- **Basic Mode**: классический кнопочный калькулятор — история вычислений,
  ячейка памяти (MC/MR/M+/M-/MS), копирование результата, ввод с клавиатуры.
- **Converter Mode**: конвертер величин (длина, масса, температура, данные,
  время, скорость). В поле значения можно вводить выражения: `2 + 3`, `sqrt(2)`.
- **Spreadsheet Mode**: в планах.

## Возможности движка

- Точная арифметика на decimal.js (`0.1 + 0.2 = 0.3`)
- Операторы `+ - * / % ^` с корректными приоритетами, `^` правоассоциативна
- Постфиксный факториал: `5!`, `2^3!` = 64
- Научная нотация: `1e3`, `2.5e-2`
- Константы `pi`, `e`; комментарии `//`
- Функции: тригонометрия (`sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `atan2`,
  `sinh`, `cosh`, `tanh`), степени и корни (`sqrt`, `cbrt`, `pow`, `exp`),
  логарифмы (`log` = log10, `ln`, `log2`), округление (`round`, `floor`,
  `ceil`, `trunc`), а также `abs`, `sign`, `min`, `max`

## Система билда

- **Основной стек**: TypeScript + Vite (vanilla DOM, без UI-фреймворка)
- **Парсер**: собственный рекурсивный спуск (лексер → парсер → эвалуатор)
- **Вычисления**: decimal.js для точных чисел
- **Тесты**: Vitest
- **Деплой**: GitHub Pages через GitHub Actions
- **Адаптив**: каркас на `100dvh` — приложение помещается целиком даже на
  1024×600; скроллятся только внутренние области

## Структура проекта

> Реализовано: ядро (`src/core/`), режимы **Text**, **Basic** и **Converter**
> (`src/modes/`), UI-оболочка с темами (`src/ui/`) и автосохранение
> (`src/storage/`). В планах: Spreadsheet Mode, экспорт/импорт, IndexedDB.

```
src/
├── core/                  # Математический движок (независимый от UI)
│   ├── engine/            # Lexer, Parser, Evaluator, FunctionRegistry
│   ├── ModeRegistry.ts    # Реестр режимов-плагинов
│   └── types.ts           # Общие типы
├── modes/                 # Плагины режимов
│   ├── text/              # Text Mode (заметки-вычисления)
│   ├── basic/             # Basic Mode (кнопочный)
│   └── converter/         # Converter Mode (единицы измерения)
├── ui/                    # Оболочка: табы, темы
│   └── theme/             # Светлая/тёмная тема + адаптив
├── storage/               # LocalStorage (версионируемое)
└── main.ts                # Точка входа
```
